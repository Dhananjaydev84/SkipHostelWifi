SkipHostelWifi Privacy Policy

Last updated: July 3, 2026

What Data Is Stored

SkipHostelWifi stores your User ID locally on your device using browser extension storage.

How Your User ID Is Used

Your User ID is used only to submit the WiFi login request to the Rajagiri hostel/campus login portal.

Third-Party Sharing

This extension does not send your ID to any third-party server. It only submits it to the hostel/campus login portal.

Data Collection

SkipHostelWifi does not collect analytics, tracking data, browsing history, or personal information beyond the User ID you enter for WiFi authentication.

Contact

For questions about this policy, contact the project maintainers.
